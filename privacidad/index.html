Privacidad

Esta web no usa cookies, ni analítica, ni publicidad, ni rastreadores. Las fuentes de letra se sirven desde aquí mismo.

Los vídeos de YouTube no se cargan hasta que pulsas «play». Entonces se usa el modo de privacidad mejorada de YouTube (youtube-nocookie.com) y a partir de ese momento se aplica la política de privacidad de Google.

La web está alojada en GitHub Pages, que puede registrar datos técnicos de las visitas (como la dirección IP) por seguridad: lo explica su declaración de privacidad.
